PERQemu "experiments" branch ChangeBlog


Summary of changes on the development branch since the v0.8.5 interim release.
Previous notes moved to ChangeLog-Old.txt.


January, 2026:

    3. RS-232 update: refactored ISIODevice interface, added separate Tx/Rx baud
    rate support on EIO (only affects pacing for the PERQ side, not the host),
    and implement polling on Unix for the receiver since the C#/Mono SerialPort
    class never actually fires the damn DataReceived event.  Some limited tests
    with Chatter, Kermit and Putty/TeraTerm show that PERQ<->PERQ transfers are
    already much more reliable, but much work remains to work out a flow control
    strategy to prevent overruns when a fast host dumps a crap ton of data on
    the PERQ.  Bump to v0.8.9 for platform testing.

    2. Small update: make Windows Ethernet device selection a bit less annoying.
    Tiny bug fix in PERQmedia to make sure version # byte is set when writing to
    IMD images; in some cases it was left at zero when converting a floppy from
    another format to IMD.

    1. Didn't quite get to v1.0 by the end of 2025, but came pretty darn close.
    Audio refactoring (and Z80 SIO/DMA rework) and other improvements on track
    for a v0.9.x release in the coming weeks?  Revising the to-do lists and
    updating the roadmap for the final push; improvements to all of the utility
    programs (PERQdisk and Stut) and media library updates in the works too.
